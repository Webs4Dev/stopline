# Stopline: working rules

Follow these rules for the whole project.

The spec is at `docs/stopline-spec.md` and the diagrams are at `docs/stopline-diagrams.pdf`.

1. `stopline-spec.md` is the source of truth. `stopline-diagrams.pdf` is for reference only. If the spec needs to change, explain the change and why, wait for my "yes", then edit `stopline-spec.md`, add an entry to a "Change log" section at the end (date, what changed, why), and update the Mermaid source if a diagram is affected.
2. Work one milestone at a time (spec section 23), split into small steps.
3. Before each step: tell me what you are about to do and ask me any questions you have.
4. After each step: stop and explain in simple, non-technical words what you did, why, and how I can check it (a command to run or a file to open). Then ask before continuing.
5. Follow every rule in spec section 25.
